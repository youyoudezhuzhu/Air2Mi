## Android 16 ARM64 真机

测试使用 ARM64 手机及普通应用权限，无 Root/Termux/Shizuku。Engine 从独立的 beta.9-hardened 组件 ZIP 导入，未放入 APK。

`RuntimeSmokeTest` 实际验证：

1. 独立组件导入、平台/API/完整性校验，加载 139 个原生核心模块。
2. Engine API、Python、AES、原生接收器和实时 AAC 自检。原生接收器监听启动/停止及端口释放通过；AAC EOF 前有输出。
3. 授权状态先在 Native Host 过滤为 AVD1，商品信息从真实服务获取。未使用或重新绑定用户 CDK。
4. 用 127.0.0.1 的临时音箱配置创建接收器，自动生成标识和端口，再删除临时记录；不向真实音箱投放。
5. 关闭 Activity，等待 60 秒后 Engine 仍在运行；ActivityManager 确认真实前台服务，不只检查自有状态字段。
6. 通知栏停止动作生效，恢复标记清除。
7. 停止状态运行自检后临时宿主被关闭，不把 API/网络资源留在后台。
8. 错误平台组件被拒绝，现有组件清单及用户数据标记保持不变。

两项 instrumentation 测试通过，结果不等同于真实 iPhone → 多音箱听音验收。

## 尚待用户验收

* 实际 iPhone 投放、多音箱发现与反复扫描、物理测试音、独立音量及多音箱同步。
* 不同 Android 版本/厂商、拔掉充电线后的长时锁屏/Doze、系统回收后的实际恢复。
* 真实 CDK 激活/恢复/清除及购买浏览器跳转。授权判断仍全部由 Engine 负责。
* Android 原生组件升级后需要新进程；不能在已映射原生库的进程里做热更新或热回滚。
* 目前是 debug 签名开发 APK，正式发布还需要固定生产证书和持久可信的内核下载源。
